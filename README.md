# 🎬 Movie Genre Classification

A Machine Learning-based project that classifies movies into different genres using textual movie information and Natural Language Processing (NLP) techniques.

## 📌 Project Overview

This project builds a machine learning model to predict the genre of a movie based on its textual information.

The workflow includes data preprocessing, text feature extraction, model training, evaluation, and genre prediction.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Natural Language Processing (NLP)
- Matplotlib
- Jupyter Notebook

## 🔄 Project Workflow

1. Dataset Collection
2. Data Preprocessing
3. Text Cleaning
4. Feature Extraction
5. Train-Test Split
6. Model Training
7. Model Evaluation
8. Movie Genre Prediction
